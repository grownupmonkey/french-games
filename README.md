# Jeux de français

Jeux interactifs de français pour les classes d'Alberta. Chaque jeu est un seul fichier HTML. Ouvre `index.html` pour la page d'accueil, ou ouvre directement un jeu dans son dossier.

## Structure

- `10-3y/` : les jeux de français 10-3Y, un fichier par jeu.
- `index.html` : la page d'accueil qui relie tous les jeux.
